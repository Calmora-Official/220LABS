# 220LABS
220 LABS For project creation easily for drafts.

## What is 220 LABS actually useful for?

220 LABS allows you to easily create infinite projects for noting or just for anything that you need to draft. 220 LABS is completely free with no limits for its use. It is a great start for people to use to jot down things they often forget or for other things.

## What are the use cases for 220 LABS?

220 LABS has no limits to what you create it can be videos, PDF's, documents, videos, information and photos.
